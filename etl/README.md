# ETL (SSIS)

Esta carpeta se completa en el módulo 6. Contendrá:

- `catalogo-simulado.sql`: tablas con la misma forma que las vistas del catálogo SSISDB
  (`catalog.folders`, `catalog.projects`, `catalog.packages`, `catalog.executions`,
  `catalog.operation_messages`) y datos de ejemplo, para practicar sin un servidor SSIS.
- Instrucciones para crear un paquete real `CargaVentas.dtsx` en Visual Studio y desplegarlo en SSISDB.
